    1.1

    Metodología: identificar la variable independiente y la dependiente

    Antes de escribir una sola línea de código conviene detenerse en la pregunta de investigación y traducirla a variables. Toda elección de prueba estadística descansa en dos piezas: qué variable organiza a los sujetos en grupos y qué variable medimos para comprobar si el resultado cambia entre esos grupos.

    Lo que va antes · Los grupos que comparas

    Variable Independiente (VI) / Factor

    Es la característica o condición que clasifica a los sujetos en grupos y que pensamos que puede ocasionar o explicar los cambios en el resultado (por ejemplo, Tratamiento Placebo frente a Semaglutida, Sexo, Clase Social o Tabaquismo).

    Lo que mides · El efecto

    Variable Dependiente (VD) / Respuesta

    Es la variable clínica cuyo resultado medimos para comprobar si varía en función de los grupos de la variable independiente (por ejemplo, el nivel de colesterol en mg/dl, la edad, el IMC o sufrir un infarto Sí/No).

    Variable Independiente (Grupos / Causa) → Variable Dependiente (Medición / Efecto)

    Método paso a paso

    1. Identifica la variable dependiente y su naturaleza: cuantitativa (colesterol, edad, IMC) o cualitativa (infarto Sí/No, fumador, percepción de salud). Esta decisión abre la Rama 1 o la Rama 2 del árbol de decisión.
    2. Identifica la variable independiente y cuenta sus categorías: un único grupo frente a un valor de referencia, dos grupos o tres o más grupos.
    3. Determina si las muestras son independientes o apareadas. Son independientes cuando cada grupo está formado por sujetos distintos; son apareadas cuando medimos a los mismos sujetos en dos momentos (antes y después) o con dos métodos.
    4. Comprueba los supuestos de aplicación: normalidad (Shapiro-Wilk o Kolmogorov-Smirnov) y homogeneidad de varianzas (Levene, F de Snedecor o Bartlett) para las variables cuantitativas; frecuencias esperadas (criterio de Cochran) o pares discordantes para las cualitativas.
    5. Ejecuta la prueba elegida, interpreta el p-valor y el intervalo de confianza y traduce el resultado a su significado clínico.

    Fundamentos de R, entorno de trabajo y diccionario de funciones

    R es un lenguaje interpretado: cada instrucción se ejecuta en el momento y su resultado se guarda como un objeto en la memoria activa. Este módulo reúne todo lo necesario para trabajar con soltura antes de analizar datos: la sesión y el directorio, los paquetes, las estructuras de datos y la importación y exportación de bases de datos.

    2.1

    RStudio, la consola y las reglas básicas del lenguaje

    RStudio organiza el trabajo en cuatro paneles. Arriba a la izquierda está el editor de scripts (Source), donde se escribe el código que se quiere conservar y se ejecuta línea a línea con Ctrl + Enter o con el botón Run. Abajo a la izquierda está la consola (Console): el símbolo > indica que R está listo para recibir una orden. Arriba a la derecha, la pestaña Environment muestra todos los objetos creados en la sesión y la pestaña History registra cada instrucción ejecutada. Abajo a la derecha se agrupan Files (explorador de archivos), Plots (gráficos, con las opciones Zoom y Export), Packages (paquetes instalados y cargados) y Help (documentación).

    Reglas del lenguaje
    • R distingue mayúsculas de minúsculas: Variable, variable y VARIABLE son tres objetos distintos.
    • Los nombres de objetos empiezan por una letra (o un punto seguido de letra) y no admiten espacios, tildes ni caracteres reservados; se separan palabras con guion bajo (peso_final).
    • Todo lo que sigue a # en una línea es un comentario y no se ejecuta.
    • Las órdenes se separan con saltos de línea o con punto y coma; las llaves { } agrupan bloques.
    • Todas las funciones llevan paréntesis, reciban o no argumentos: getwd().
    Ayuda dentro de R
    • ?mean o help(mean): ayuda de una función.
    • args(mean): argumentos que admite.
    • ??plot o help.search("plot"): búsqueda por término.
    • help(package = "ggplot2") y vignette(package = "ggplot2"): documentación de un paquete.
    • search(): paquetes cargados en la sesión.

    2.4

    Vectores: la estructura más sencilla

    c()seq()rep()which()

    Un vector es una secuencia ordenada de elementos del mismo tipo (numéricos, texto o lógicos); un único número ya es un vector de longitud 1. Cada columna de un data frame es, en realidad, un vector, por lo que dominar su creación, su indexación con corchetes y las operaciones elemento a elemento es la base de todo lo demás.

    Reciclaje de vectores

    Si se suman dos vectores de distinta longitud, R recicla el más corto y lanza el aviso «longitud de objeto mayor no es múltiplo de la longitud de uno menor». Por ejemplo, c(2, 5, 10) + c(2, 5, 10, 8) devuelve 4 10 20 10: al último valor del segundo vector le suma de nuevo el primero del primero. Para evitar resultados inesperados, opera siempre con vectores de igual longitud.

    2.5

    Matrices: datos bidimensionales del mismo tipo

    matrix()rbind()cbind()t()

    Una matriz es una colección bidimensional de elementos del mismo tipo. En bioestadística se usa sobre todo para introducir manualmente tablas de contingencia a partir de los recuentos de un enunciado, antes de aplicar chisq.test(), fisher.test() o mcnemar.test(). Por defecto, matrix() rellena por columnas; con byrow = TRUE rellena por filas, que es como se leen las tablas.

    Creación, transformación y filtrado de variables

    Las bases de datos casi nunca llegan listas para analizar. Antes de describir o contrastar hay que construir las variables que pide el enunciado (la edad a partir de la fecha de nacimiento, el IMC, la hipertensión a partir de la tensión arterial), cambiar nombres, ordenar y seleccionar el subgrupo de pacientes que interesa.

    3.1

    Cálculo de la edad en años cumplidos a partir de la fecha de nacimiento

    as.Date()round()as.numeric()Fecha de cierre del enunciado

    La variable fech_nac se importa como texto (character), por lo que R no puede operar con ella. El primer paso es convertirla en fecha con as.Date(); después se resta a la fecha de cierre del seguimiento que indique el enunciado (por ejemplo, el 31/12/2025 o el 31/12/2023). La resta devuelve una diferencia en días, que se divide entre 365.25 para tener en cuenta los años bisiestos. Por último se redondea a número entero y se convierte en numérica con as.numeric(), eliminando la etiqueta de «diferencia de tiempo».

    Importante cambiar en tu código
    • "2025-12-31"fecha de cierre del enunciado, siempre como "AAAA-MM-DD"
    • fech_nacnombre de la variable con la fecha de nacimiento
    • edadnombre de la nueva variable
    Nota metodológica

    round() redondea al entero más próximo, que es el criterio utilizado en las prácticas. Si un enunciado exige la edad en años cumplidos estrictos (sin haber alcanzado aún el siguiente cumpleaños), sustituye round(…, 0) por floor(…), que trunca hacia abajo: 43.40 pasa a 43 y 86.83 pasa a 86.

    3.2

    Creación de variables mediante operaciones matemáticas: diferencias e IMC

    Operaciones entre columnasround(…, 2)

    Conversión a factores, etiquetado, recodificación y nivel de referencia

    R interpreta los números como valores matemáticos con los que se puede sumar o promediar. Al transformar una variable en factor le indicamos que esos valores son en realidad categorías o grupos cualitativos, de modo que pueda agruparlos, contarlos y compararlos correctamente en tablas, gráficos y contrastes.

    4.1

    Qué es un factor: niveles internos y etiquetas visibles

    as.factor()levels()table(useNA)

    Un factor asigna a cada valor distinto de la variable un nivel interno numérico (levels, los números 1, 2, 3… con los que opera R) y una etiqueta visible (labels, el texto que leemos). La confusión habitual entre ambos se resuelve al comprobar que, aunque veamos «Mujer» y «Varón», internamente R trabaja con 1 y 2. Si no se especifica un orden, R coloca los niveles en orden alfanumérico, y el primero de ellos actuará como categoría de referencia en los modelos estadísticos.

    Lectura de la salida

El vector numérico muestra los códigos internos: 1 = Alta, 2 = Baja y 3 = Media, que no coinciden con ningún orden lógico; por eso conviene fijar los niveles a mano (apartado 4.4).

    4.2

    Construcción de factores etiquetados con factor(levels, labels)

    factor()0 / 1 / 2 → texto

    Cuando una variable cualitativa está codificada con números (0 = Placebo, 1 = Semaglutida 2.4 mg, 2 = Semaglutida 7.2 mg), se construye el factor indicando en levels los códigos originales y en labels las etiquetas en el mismo orden. El orden de levels fija además el orden de las categorías en tablas y gráficos y la categoría de referencia (la primera).

    Ejecuta la conversión una sola vez

    Si ejecutas dos veces factor(x, levels = c(0, 1), labels = …) sobre la misma variable, la segunda vez ya no encuentra los códigos 0 y 1 (ahora contiene "No" y "Sí") y convierte toda la columna en NA. Si ocurre, recupera la variable desde la copia de seguridad (datos.backup) o vuelve a importar el archivo.

    ifelse() frente a factor()

    Con ifelse(x == 0, "Mujer", "Varón") se obtiene una variable de texto, que R no trata como categoría hasta convertirla con as.factor(). Con factor(levels, labels) se obtiene directamente un factor con su orden de niveles, que es lo que necesitan table(), boxplot(), leveneTest() o aov().

    4.3

    Agrupación de variables continuas en intervalos con cut()

    cut(breaks, labels)right = FALSE-Inf · Inf

    La función cut() transforma una variable cuantitativa en un factor ordinal a partir de unos puntos de corte (breaks) y unos nombres (labels); el resultado ya es un factor, por lo que no hace falta convertirlo. Los extremos -Inf e Inf garantizan que ningún valor quede fuera. Siempre hay un nombre menos que puntos de corte: con c(-Inf, 20, 30, Inf) se crean tres intervalos.

    Cómo leer los intervalos de cut()

    Punto relleno: el valor de corte se incluye en el intervalo de la izquierda. Punto hueco: el valor de corte pasa al intervalo de la derecha.

    Cuándo añadir right = FALSE

    Por defecto (right = TRUE) los intervalos son abiertos por la izquierda y cerrados por la derecha, (a, b]: el valor del corte pertenece a la categoría inferior. Si el enunciado pide que el valor de corte se incluya en la categoría superior, por ejemplo «normal si 20 <= IMC < 30» y «obesidad si IMC >= 30», los intervalos deben ser [a, b) y hay que añadir right = FALSE.

    Agrupación de niveles existentes y orden de las categorías

    Los niveles de un factor pueden fusionarse asignando a levels() un vector con el nuevo nombre de cada nivel original: los niveles que reciben el mismo nombre se agrupan. También se puede imponer un orden distinto del alfabético al crear el factor, lo que permite corregir códigos mal escritos o colocar las categorías en su orden lógico (Baja, Media, Alta).

    El RIC mide la dispersión del 50 % central de los sujetos de la muestra, es decir, la amplitud del intervalo comprendido entre el percentil 25 y el percentil 75.     5.4

    Forma de la distribución: asimetría y apuntamiento

    La asimetría (skewness) indica el grado y la dirección de la falta de simetría: un valor próximo a 0 sugiere simetría, un valor positivo indica una cola más larga hacia los valores altos y uno negativo, una cola más larga hacia los valores bajos. El apuntamiento (curtosis) mide la concentración de los datos en el centro: con la curtosis normalizada que devuelven e1071 y psych, 0 corresponde a una distribución mesocúrtica (como la normal), los valores positivos a una leptocúrtica (más apuntada y con colas más pesadas) y los negativos a una platicúrtica (más aplanada).

    Cómo leer las formas

    • 2Simétrica (skew ≈ 0): media y mediana coinciden.
    • 3Asimetría positiva (skew > 0): la cola larga va hacia los valores altos, como el colesterol (0.58).
    • 4Leptocúrtica (> 0), mesocúrtica (0) y platicúrtica (< 0): la edad, con -1.21, es claramente platicúrtica.
    Interpretación de los resultados

    La edad es prácticamente simétrica (0.04) pero platicúrtica (-1.21): los pacientes se reparten de forma muy homogénea entre los 35 y los 93 años, sin una concentración marcada alrededor de la media. El colesterol presenta una asimetría positiva moderada (0.58), con una cola de valores altos, y es ligeramente platicúrtico (-0.47).     margin = 1 · filas

    Comprobación del equilibrio de los grupos del estudio: Test de Chi-cuadrado de Pearson

    chisq.test()VI: brazo de tratamientoVD: géneroEsperados ≥ 5
    1Justificación del estudio

    Para comprobar si los brazos de un ensayo son comparables en una característica basal se necesita un contraste de hipótesis. Queremos saber si la distribución de una variable cualitativa (el género) es la misma en varios grupos independientes (los tres brazos de tratamiento), por lo que selecciono el Test de Chi-cuadrado de Pearson, aplicable porque todas las frecuencias esperadas son mayores o iguales que 5. El test evalúa si las diferencias observadas en la tabla son atribuibles al azar o si algún grupo está realmente desequilibrado, lo que podría confundir la comparación posterior de los tratamientos.

    2Hipótesis del contraste
    Hipótesis
    H0

    Hipótesis Nula: los grupos están equilibrados; la proporción de hombres y mujeres es la misma en los tres brazos de tratamiento (género y tratamiento son independientes).

    H1

    Hipótesis Alternativa: los grupos NO están equilibrados; al menos un brazo tiene una distribución por género distinta.

    Interpretación de resultados
    Si p-valor < 0.05

    Rechazamos la hipótesis nula: existe al menos una diferencia significativa en la distribución por género entre los brazos, por lo que los grupos NO están equilibrados. En este ejemplo, p = 0.007, y el siguiente paso es identificar qué grupo rompe el equilibrio.

    Si p-valor > 0.05

    No podemos rechazar la hipótesis nula: no hay pruebas suficientes para afirmar que los grupos sean distintos en su composición por género y, por tanto, los grupos están equilibrados y son comparables en esta característica.

    Un desequilibrio basal no invalida el ensayo, pero obliga a tenerlo en cuenta: si el género influye en la respuesta al tratamiento, las diferencias entre brazos podrían deberse en parte a su distinta composición.

    El p-valor solo indica que existe desequilibrio, no dónde. Primero se comparan las frecuencias relativas por filas, porque el conteo absoluto no permite comparar grupos de distinto tamaño. Después se confirma la sospecha comparando las frecuencias observadas (personas reales) con las frecuencias esperadas que ha calculado el test, que representan lo que debería haber ocurrido si los grupos estuvieran perfectamente equilibrados. Los residuos estandarizados cuantifican esa desviación: valores mayores que 1.96 en valor absoluto señalan las celdas responsables.

    Redacción del origen del desequilibrio

    Para identificar el origen del desequilibrio observamos primero las frecuencias relativas por filas: el brazo de semaglutida 2.4 mg tiene un 65 % de mujeres, frente al 52 % del placebo y el 51 % de semaglutida 7.2 mg, lo que hace sospechar que ahí radica el desequilibrio.     Distribuciones de probabilidad e intervalos de confianza

    Las distribuciones de probabilidad describen cómo se reparten los resultados posibles de una variable aleatoria y son la base de todos los contrastes: cada p-valor es un área bajo una de ellas. A partir de esas mismas distribuciones se construyen los intervalos de confianza, que estiman el valor poblacional de una media o de una proporción con una precisión conocida.

    8.1

Así, dbinom, pbinom, qbinom y rbinom son las cuatro funciones de la binomial. Las discretas que se estudian son la binomial y la de Poisson; las continuas, la normal, la T de Student, la F de Snedecor y la chi-cuadrado.

    1Qué significa un intervalo de confianza

    Un intervalo de confianza es un rango de valores que refleja la variabilidad entre la estimación obtenida en la muestra y el verdadero valor poblacional. Se construye con la media muestral y un margen de error que depende de la desviación típica, del tamaño muestral y del nivel de confianza: IC = media ± t × (DT / raíz de n). Un IC del 95 % significa que, si se repitiera muchas veces el estudio con muestras obtenidas del mismo modo, el 95 % de los intervalos construidos contendrían el verdadero valor. Al pasar del 95 % al 99 % el intervalo se ensancha: ganamos confianza a costa de perder precisión.

    Interpretación de resultados

El IC del 99 % (61.25 a 64.05) es más amplio. El p-valor que acompaña a t.test() contrasta si la media es 0, una hipótesis sin interés clínico en este caso. Por clase social, el colesterol medio de la clase alta (179.7 mg/dl; IC 95 %: 174.1 a 185.3) no se solapa con los de la clase baja (189.2 a 194.8) y media (188.1 a 193.1), lo que anticipa las diferencias que confirmará el ANOVA.

    Intervalo de confianza alrededor de una proporción: Wald, Wilson y exacto

El método de Wald (asintótico) es el más utilizado y se basa en la aproximación normal: IC = p ± z × raíz de [p (1 - p) / n]. Con proporciones próximas a 0 o a 1, o con muestras pequeñas, puede dar límites inadecuados; en esas situaciones es preferible el método de Wilson, más preciso y con mejor cobertura, o el método exacto de Clopper-Pearson, basado en la distribución binomial.

    H0

    Hipótesis Nula: las proporciones marginales son iguales; no hay un cambio significativo entre el estado inicial y el final (las discordancias son simétricas: b = c).

    H1

    Hipótesis Alternativa: las proporciones han cambiado significativamente entre las dos mediciones (b ≠ c).

    3Código, adaptación, salida e interpretación
    Importante cambiar en tu código
    • fum · fum_pla variable antes (filas) y después (columnas)
    • iam2 == "Sí"condición que define el subgrupo
    Interpretación de resultados
    Si p-valor < 0.05

    Los pares discordantes suman 65 (≥ 10), por lo que aplicamos McNemar sin corrección de Yates y obtenemos un p-valor de 7.5e-16. Al ser menor de 0.05, rechazamos la hipótesis nula y concluimos que el cambio observado es estadísticamente significativo: la proporción de fumadores tras el infarto (18.0 %) es diferente de la proporción inicial (24.6 %) en los mismos pacientes. En el subgrupo con reinfarto (b + c = 12) el resultado es el mismo (p = 0.0005).

    Si p-valor > 0.05

    No podríamos rechazar la hipótesis nula: no existiría evidencia estadística para afirmar que la proporción de fumadores haya cambiado tras el evento, y aceptaríamos que ambas proporciones son iguales.

    Significado clínico: 65 pacientes dejaron de fumar tras el infarto y ninguno empezó a fumar (b = 0). Con o sin corrección de Yates, la conclusión es idéntica; la corrección solo modifica ligeramente el estadístico.

    12.5

    Muestras apareadas politómicas u ordinales · Prueba de Friedman

    friedman.test()as.matrix(cbind(antes, después))
    1Justificación del estudio

    Se quiere comparar la percepción del estado de salud antes y después del primer infarto en los mismos pacientes. Es una variable cualitativa ordinal con más de dos categorías (de «Muy mala» a «Muy buena»), por lo que McNemar, limitado a tablas 2 × 2, no es aplicable. Selecciono la prueba de Friedman, el equivalente no paramétrico de un diseño de medidas repetidas: asigna a cada paciente los rangos de sus mediciones y contrasta si las variables relacionadas proceden de la misma población. Necesita los datos en forma de matriz numérica con una fila por paciente y una columna por momento.

    H1

    12.6

    Asociación entre una variable dicotómica y una ordinal · Chi-cuadrado de tendencia lineal

    prop.trend.test(x, n, score)VI ordinal (3+ niveles)
    1Justificación del estudio

    Cuando la variable independiente es ordinal (clase social baja, media y alta) y la dependiente es dicotómica (fumar o tener diabetes), el Chi-cuadrado de Pearson trata las categorías como si no tuvieran orden y pierde potencia. Si la pregunta es si la proporción aumenta o disminuye de forma sistemática al subir de categoría, selecciono el test de Chi-cuadrado de tendencia lineal, que contrasta una relación lineal creciente o decreciente entre las proporciones y el orden de los grupos. prop.trend.test() necesita el vector de «éxitos» (x) y el de totales (n) de cada categoría, en su orden.

    2Hipótesis del contraste
    Hipótesis
    H0

    Hipótesis Nula: no existe tendencia lineal en las proporciones a lo largo de las categorías ordenadas.

    H1

    Hipótesis Alternativa: la proporción aumenta o disminuye de forma lineal al avanzar en las categorías.

    3Código, adaptación, salida e interpretación
    Importante cambiar en tu código

    • scorepuntuación de cada categoría ordinal (1, 2, 3…)
    Interpretación de resultados
    Si p-valor < 0.05

    En la diabetes, el p-valor es 7.6e-11: rechazamos la hipótesis nula y concluimos que existe una tendencia lineal decreciente en la proporción de diabéticos a medida que aumenta la clase social (24.4 %, 10.0 % y 4.3 %), compatible con estilos de vida más saludables en las clases altas.

    Si p-valor > 0.05

    En el tabaquismo, aunque la proporción de fumadores parece descender en la clase alta (25.1 %, 25.8 % y 16.0 %), el p-valor es 0.234: no podemos rechazar la hipótesis nula y no se reconoce una tendencia lineal significativa.

    Módulo 13Práctica 10 y entrega de trabajos

    Guía de compilación en RStudio (Knit a HTML, Word o PDF) y resolución de errores

    Un documento RMarkdown (.Rmd) combina texto, código y resultados. Al terminar un examen o un proyecto se compila con el botón Knit para obtener un informe en HTML, Word o PDF. La compilación solo funciona si el documento se puede ejecutar de principio a fin sin intervención: este módulo explica por qué falla y cómo arreglarlo en minutos.

    13.1

    Qué ocurre exactamente al pulsar Knit

    Sesión limpiaChunks de arriba abajoDirectorio del .Rmd
    1. RStudio abre una sesión de R limpia, desde cero. No ve los objetos de tu pestaña Environment ni los paquetes que tengas cargados en la consola: solo existe lo que el propio documento crea.
    2. Ejecuta todos los bloques de código (chunks) por orden estricto de arriba abajo. Si un chunk usa un objeto o una función que todavía no se ha creado o cargado en un chunk anterior, la compilación se detiene.
    3. El directorio de trabajo es la carpeta donde está guardado el .Rmd. El archivo de datos (df_iam3_r.csv) debe estar en esa misma carpeta, o hay que indicar su ruta completa.
    4. Combina el texto, el código y las salidas en el formato elegido en el encabezado YAML (html_document, word_document o pdf_document) y abre el resultado.
    Regla crítica de las librerías

    Jamás dejes un install.packages("…") activo sin comentar dentro del .Rmd. Pon siempre una almohadilla delante para que quede comentado y deja sin almohadilla únicamente la carga del paquete:

    Orden de las variables

    Toda carga de la base de datos (datos <- read.csv(…)) y toda transformación a factor o creación de variables (datos$edad, datos$clas_soc <- as.factor(…)) debe estar en un chunk anterior al bloque donde se utilice. Si trabajas en la consola y luego copias el código al .Rmd, revisa que no falte ningún paso intermedio.

    13.2

    Cómo localizar y corregir un fallo al compilar

    Pestaña RenderQuitting from lines XX-YY
    1. Lee la pestaña Render (junto a la consola, abajo a la izquierda). Cuando la compilación falla, muestra un mensaje del tipo Quitting from lines 245-252 (examen.Rmd) seguido del error de R.
    2. Ve a esas líneas del .Rmd: el chunk que empieza en la línea indicada es el que ha fallado.
    3. Ejecuta ese chunk a mano con el botón de reproducción verde de su esquina (o Ctrl + Shift + Enter) después de ejecutar todos los anteriores (Ctrl + Alt + P, «Run All Chunks Above»), para reproducir el error en las mismas condiciones que Knit.
    4. Comprueba las causas más frecuentes: tildes en los niveles ("Sí" frente a "Si"), paréntesis o comillas sin cerrar, una coma olvidada, o una función cuya librería no se ha cargado antes con library().

    13.3

    Estructura base de un documento .Rmd y opciones de los chunks

    YAMLecho · eval · includemessage · warning

    Un .Rmd empieza con un encabezado YAML entre tres guiones que define el título, el autor, la fecha y el formato de salida. Después se alternan párrafos de texto en Markdown (los títulos se escriben con #, ## y ### seguidos de un espacio) y chunks de código delimitados por tres comillas invertidas con {r}. Las opciones de cada chunk controlan qué se muestra en el informe.

    Opción del chunkEfecto
    echo = FALSEEjecuta el código y muestra el resultado, pero oculta el código
    eval = FALSEMuestra el código sin ejecutarlo (útil para ejemplos con variables que no existen en tu base)
    include = FALSEEjecuta el código sin mostrar ni el código ni el resultado (chunk de configuración)
    message = FALSE · warning = FALSEOculta los mensajes y avisos al cargar paquetes
    fig.width = 8, fig.height = 5Tamaño de los gráficos en pulgadas
    output: word_document · pdf_documentCambia el formato del informe en el YAML (el PDF requiere LaTeX: tinytex::install_tinytex())
    Lista de comprobación antes de pulsar Knit
    • El .Rmd y el .csv están en la misma carpeta.
    • Todos los install.packages() están comentados con #.
    • Cada library() aparece antes del primer uso de sus funciones.
    • La carga de datos y las transformaciones están al principio.
    • Los niveles de los factores están escritos exactamente igual que en la base (tildes y mayúsculas).
    • Cada gráfico en cuadrícula termina con par(mfrow = c(1, 1)).
    • Has ejecutado «Run All» (Ctrl + Alt + R) en una sesión reiniciada (Session > Restart R) sin errores.
